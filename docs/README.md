# AI利用ポリシー
今回から、AIの利用を条件付きで容認します。

### 条件
- コード生成をさせるのではなく、相談相手として利用すること：[AIメンター](#AIメンター)

AIメンターとしてAIを使う場合でも、**最終的にコードがもたらす結果に責任を持つのは自分自身**だということを忘れないでください。 
AIが教えてくれたコードが何をしているのかを理解し、**チームメイトに説明できるように**しておいてください。 
誰も理解していないコードが積み上がっていくことがないように、チームメイトとよく相談して、計画的に運用してください。

## AIメンター
2種類の方法を案内します。どちらを使っても大きくは変わりません。

AIに課金していない人：[ChatGPTメンター.md](ChatGPTメンター.md) 
無料版のChatGPTに自分のレポジトリの情報を与えて相談する方法を案内します。

AIに課金している人：このまま使えます 
レポジトリのAGENTS.mdが自動的に適用されます。  
事前導入されているAIメンター設定を使用する場合は、[AIメンター.md](/AI_mentor.md)のファイルパスを渡してあげてください。

# この学習のゴール

### プロジェクト経験：開発全体を見通す視点を身に付ける
- 開発プロジェクト全体を経験すること
- チームでタスクとスケジュールの状況を共有し、計画的に開発を進めること
- 春休みの時点で、実ユーザーを抱えるプロジェクトに参加できる状態になること

### エンジニアとしての自立：自走力をつける
- issue作成->優先順位付け->issue着手->PR提出->レビュー->マージまでの一連の流れを回せるようになること
- 分からないことを自分で調べて解決できるようになること
- AIを活用し、うまくいった経験、いかなかった経験の両方から教訓を得ること

# 環境構築

1. 代表者が、このレポジトリの「Use this template」→「Create a new repository」から、チームのレポジトリを作る
   - Owner：**winc1980**（自分の個人アカウントにしない）
   - Repository name：プロジェクト名
   - Visibility：**Public**（mainブランチの保護が効くのはpublicだけです）
2. チームのレポジトリの Settings → Collaborators and teams で、チームメンバーに Write 権限を与える（メンバーを個別に追加する、もしくは@winc1980/2026チームを追加する）
3. チームメンバーがgit cloneをする
4. README.mdとAGENTS.mdにプロジェクトのコンセプトを書き込む
5. 使用する技術に合わせた環境構築：2週目からそれぞれのプロジェクトの事情に合わせて進めていきます

リポジトリの設定（Discord通知・mainブランチの保護など）：[リポジトリ設定](リポジトリ設定.md)

# リポジトリ設定

## どんなときに読むもの？
環境構築でチームのリポジトリを作ったあと、使いやすくしたいときに読んでください。
設定は代表者が1回やれば済みます。どれも必須ではありません。チームで相談して、必要なものだけ設定してください。

# 1.Discordに通知を流す

issue・PR・レビューの動きを、Discordのチャンネルに自動で流します。
GitHubを開かなくてもチームの動きが見えます。**動きがないこと自体も見えます。**

1. Discord：通知を流したいチャンネルの「チャンネルの編集」→「連携サービス」→「ウェブフック」→「新しいウェブフック」を作り、URLをコピーする
2. GitHub：リポジトリの Settings → Webhooks → Add webhook
   - **Payload URL**：コピーしたURLの末尾に `/github` を付けたもの
   - **Content type**：`application/json`
   - **Which events…**：「Let me select individual events」を選び、Issues・Pull requests・Pull request reviews などにチェックする（「Send me everything」だとpushのたびに流れて騒がしくなります）
3. 保存すると、テスト通知が届きます

> 💡 通知用のチャンネルは、会話用とは分けておくと、話が通知に埋もれません。フォーラムではなく、通常のテキストチャンネルを使ってください。


# 2.mainブランチを保護する

mainへの直接pushを禁止し、PRを出してチームメイトの承認をもらわないとマージできないようにします。
[README](README.md#prを確認してマージする) の「PRを確認してマージする」流れを、仕組みで守るための設定です。

リポジトリの Settings → Rules → Rulesets → New ruleset → New branch ruleset

- **Ruleset Name**：`main`（何でもよい）
- **Enforcement status**：Active
- **Target branches**：Add target → Include default branch
- **Rules**：
  - 「Require a pull request before merging」にチェックし、Required approvals を `1` にする
  - 「Block force pushes」にチェック（最初からチェック済み）

> ⚠️ winc1980は無料プランなので、**privateリポジトリだとこの設定は効きません。** 環境構築のとおりPublicで作っていれば効きます。
> 事情があってprivateにした場合は、「mainに直接pushしない」をチームのルールとして決めておきましょう。


# 3.Projectsのボードを自動で動かす

GitHub Projects を使うと、issueとPRをボードで一覧できます。誰が何をやっているかが一目で分かります。

### ボードを作る
1. リポジトリの Projects タブ → New project → Board を選ぶ
2. ボードはリポジトリではなく **winc1980 の持ち物** になります。ボード右上の「…」→ Settings → Manage access で、チームメンバー（または@winc1980/2026）に Write を付けてください。付けないと、メンバーがボードを動かせないことがあります
3. 列（Status）はチームで決めてください。最初は用意されている Todo / In Progress / Done の3つで十分です

### 自動化を設定する
ボード右上の「…」→ Workflows から、次を有効にします。コードは要りません（最初から有効なものもあります）。

| ワークフロー | 設定 |
|---|---|
| Auto-add to project | このリポジトリのissueとPRを、自動でボードに追加する |
| Item added to project | 追加されたら Status を Todo にする |
| Item closed | issueが閉じたら Status を Done にする |
| Pull request merged | PRがマージされたら Status を Done にする |

PR本文に `closes #番号` を書いておけば（[git操作](git操作.md)）、マージしたときにissueが閉じ、ボードも自動で Done に移ります。

# タスク
タスクは以下の順番に進めていきます。

## タスクを取る
チームにとって優先順位が高いタスクの中で、自分にできそうなものを選びます。
同時に進めるのは1個だけです。難しすぎたり、他のタスクを待つ必要があって詰まった時は、すぐにチームメイトに相談しましょう。

## 実装する
自力で調べて、頑張って実装してください。AIに相談してもOKです。
それでも分からないときは、チームメイトに聞くか、学習会メンターをメンションして相談してください。必ず力になります。

詰まったときの進め方：[詰まったとき](詰まったとき.md)

## PR(プルリクエスト)を出す
実装を終えたら、まずは動作確認をします。タスクの要件を満たす動作が確認できたら、レビューしてくれるチームメイトのために説明文を書きましょう。

レビューで指摘を受けたら、修正します。指摘がたくさんあっても、落ち込まなくて大丈夫です。大学の試験と違って、ミスがあっても直して再提出できます。全部直せば100点です。

## PRをレビューしてマージする
チームメイトのPRをレビューします。AIと一緒にやってもOKです。動作確認をして、おかしなところがあれば、できる限り具体的な場所を特定して指摘します。実装した本人には気付けない間違いというのは誰にでもあるものなので、遠慮せずに指摘してあげてください。 

すべての指摘の修正を見届けたら、mainブランチにマージしましょう。これにて、タスク完了です。お疲れ様でした。

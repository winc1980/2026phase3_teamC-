# 2026phase3_teamC

## 概要

**モールス信号で、こっそり・片手でメモが取れるアプリ**

ボタンでモールス信号を入力すると、日本語に変換して文字起こしします。
取ったメモはそのままチャットで相手に送ることもできます。

## ゴール

| 段階 | 内容 |
| --- | --- |
| Goal 1 | メモ取り（モールス信号、音声など） |
| Goal 2 | 相手に通信して内容を読み上げる |
| Goal 3 | LINEを超えるチャットアプリ |

## 機能要件

1. **メモ取り**：スマホの画面を開かなくても、モールス信号や音声でメモが取れる
2. **読み上げ**：取ったメモを通信で相手に送り、読み上げる
3. **チャット**：LINEの上位互換となるチャット機能

## 既存のメモアプリとの違い

### メモを取っていると気づかれない

メモアプリや紙のノートを出しにくい場面でも、すぐにメモが取れます。

- 上司との会議中や、上司に怒られているとき
- 散歩中
- ひき逃げなどの事件を目撃したとき
- 痴漢などの被害にあったとき（性別を問わず起こりうる）
- 緊急時のSOS

### 片手間で入力できる

- モールス信号なら、画面を見ずに片手で入力できる
- 指が太くても入力しやすい
- よく使う文字列をプリセットとして登録しておく案もある
